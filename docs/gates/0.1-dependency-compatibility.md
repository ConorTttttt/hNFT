## API compatibility analysis

Holochain 0.7.1 includes breaking changes relative to 0.7.0.

1. **Capability grants (required):** coordinator `init()` used
   `ZomeCallCapGrant` and `CapAccess::Unrestricted`. Replaced with
   `CapGrant::new_zome_call_grant(..., GrantConstraint::Unrestricted, ...)`
   per the published upgrade guide.
2. **Direct signals (not currently used):** hNFT uses the remote zome
   function `recv_remote_signal` and `emit_signal` for local UI delivery.
   It does not use `Signal::AppDirect` or app-interface direct signaling,
   so the new direct-signal capability grant is not currently required.
3. **Other removed APIs:** inspected coordinator, integrity and test sources
   for `Entry::app_fancy`, `Entry::entry_type`, and `Action::signer`;
   no matches were found. Confirm this via compilation.
4. **JavaScript client:** `0.21.1` supports Holochain 0.7.1. hNFT's
   wrapper uses `callZome` and app signals, not `ChainOp` accessors,
   which received a serialization fix in 0.21.1. Confirm UI typecheck
   and runtime behavior.
5. **Data/DNA compatibility:** changed integrity-zome bytes change DNA
   hash; Holochain 0.7.0 grants cannot be read by 0.7.1. All migration
   assumptions must be reviewed before using any non-disposable collection.

## Environment limitation and classifications

This audit environment cannot run the Nix/Holochain toolchain or contact
external package registries from its shell. The machine has Node 22,
npm 10, no `rustc`/`cargo` and no Nix; it is **not** an approved hNFT
development environment. Consequently there are **no claimed successful
fresh-build or Sweettest runs from this session**.

**Blocker classifications:**

- **G01-ENV (environment):** no Nix / Rust toolchain and no registry
  access locally. Mitigation: Nix-backed GitHub Actions run and a clean
  developer machine.
- **G01-LOCK (reproducibility):** old Holochain revisions in `flake.lock`
  and `Cargo.lock`, mismatched npm lock(s). Mitigation: generated
  lockfile commit, reviewed before merge.
- **G01-API (potential compile/runtime):** Holochain 0.7.1 capability
  grant migration changed in coordinator. Source patch supplied; only
  actual compilation and Sweettests can prove it.
- **G01-REGRESSION (unknown):** no 0.7.1 integration results yet.
  Classify each failing test with exact logs before acceptance.

**Gate decision: NO-GO until ALL acceptance evidence is green and
critical incompatibilities are resolved.** Do not merge the gate PR
as a completed baseline based solely on source inspection.
